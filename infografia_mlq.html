MLQ: Multilevel Queue Scheduling

Not all processes are equal, so they don't wait in the same line.

NQuick glossary

CPU: the unit that executes instructions.
Process: a program in execution.
Ready queue: processes waiting for the CPU.
Quantum: maximum CPU time per turn.
Preemption: taking the CPU away from a running process.
Starvation: waiting indefinitely.
Round Robin: turns of one quantum, in a circle.
Waiting time: time spent in the ready queue.
Turnaround time: from arrival until completion.

BWhat is it?

A CPU scheduling algorithm that splits the ready queue into several independent queues, one for each type of process.

GMain features

Fixed queues

Rule between queues

DTwo ways to share the CPU among queues

Strict (fixed) priority
  • A queue is served only if all higher-priority queues are empty.
  • If a process arrives in a higher queue, the running process from a lower queue is preempted and goes back to wait in its own queue.
Time-percentage sharing

Each queue gets a fraction of CPU time. Classic example:

80 % interactive queue (Round Robin)
20 % batch queue (FCFS)
